# Weight Tracking App

This expands your original Android starter app into a fuller mobile project with profile, goals, entries, notes, charts, BMI, milestones, reminders, local Room storage, edit/delete, and CSV export.

## Open it
1. Extract the ZIP.
2. Open `WeightTrackingApp` in Android Studio.
3. Let Gradle sync.
4. Run on emulator or device.

## Features included
- user profile
- starting/current/goal weight
- dated entries
- notes per entry
- edit/delete
- history
- line chart
- BMI
- progress summary
- milestone tracking
- reminders
- unit selection
- local data storage
- CSV export
- validation and error handling

## Notes
- Min SDK 26
- Notifications need permission on Android 13+
- Exports go to the app external files folder under `exports/weight_history.csv`
